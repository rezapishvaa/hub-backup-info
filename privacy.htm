Privacy Policy

Last updated: 29 October 2026

This Privacy Policy describes how Hub Backup ("the application") handles data when the operator authorizes it to access their Google Drive account. Hub Backup is a self-hosted utility operated by a single individual for the purpose of backing up their own server. It is not a public service and has no end users other than the operator.

1. What data the application accesses

With the operator's explicit consent, Hub Backup uses OAuth 2.0 to access their Google Drive account. It requests only the drive.file scope, which grants access only to files and folders that the application itself creates or that the operator explicitly shares with it. The application cannot see, read, modify, or delete any other files in the user's Google Drive.

The application does not access:

  • Gmail, Calendar, Contacts, or any other Google service.
  • Files in the user's Drive that were not created or shared by the application.
  • Any personal information beyond the OAuth credentials needed to upload backups.

2. What data the application collects

Hub Backup does not collect, transmit, or store any personal information about the operator or any third party. The data it uploads to Google Drive consists solely of:

  • Database dumps from the operator's own server.
  • Compressed archives of the operator's own application files.
  • Configuration files and encryption manifests.

These files contain only the operator's own data and are never sent to any third party. The application has no analytics, no tracking, no telemetry, and no server component that receives data.

3. How data is stored

Backups are stored in the operator's own Google Drive account, in a folder the operator chooses. Data is retained for a configurable number of days (currently 14) and then automatically deleted by the application according to the operator's retention policy. Google's own privacy policy governs how Google stores this data on its servers.

4. Sharing of data

Hub Backup does not share any data with third parties. The application is entirely self-hosted, does not contact any external server other than the Google Drive API, and does not sell, rent, or trade any data.

5. Security

OAuth tokens are stored on the operator's own server with restrictive file permissions (0600, owned by root). Backups may be encrypted at rest with age encryption before upload. The application does not transmit tokens to any third party.

6. User control and revocation

The operator may revoke the application's access to their Google account at any time by visiting https://myaccount.google.com/permissions and removing Hub Backup. Revoking access immediately stops all further backups. Already-uploaded backups can be deleted directly from Google Drive at any time.

7. Data deletion

Because all data is stored in the operator's own Google Drive, the operator can delete any backup by deleting it from their Drive. Uninstalling the application from the server (or revoking OAuth access) removes all local credentials.

8. Changes to this policy

If this policy changes, the updated date at the top of this page will be revised. Because the application has a single operator who is also the maintainer, changes take effect immediately.
