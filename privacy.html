Privacy Policy for Hub Backup

Last updated: October 29, 2026

This Privacy Policy describes how the self-hosted utility Hub Backup ("the Application") handles data when the operator authorizes it to access their Google Drive account. The Application is operated by a single individual for the purpose of backing up their own server.

1. What Data the Application Accesses

With the operator's explicit consent, Hub Backup uses OAuth 2.0 to access their Google Drive. It requests only the drive.file scope, which grants access only to files and folders that the Application itself creates or that the operator explicitly shares with it. The Application cannot see, read, modify, or delete any other files in the user's Google Drive. It does not access Gmail, Calendar, Contacts, or any other Google service.

2. How Google User Data is Used, Stored, and Shared

The data accessed by Hub Backup is used exclusively for the purpose of creating and uploading backups of the operator's own server. The Application does not collect, transmit, or store any personal information about the operator or any third party. The data it uploads consists solely of the operator's own database dumps, application archives, and configuration files. This data is stored in the operator's own Google Drive account and is never shared with any third party.

3. Data Retention and Deletion

Backups are retained for a configurable number of days and are automatically deleted by the Application according to the operator's retention policy. The operator can delete any backup at any time directly from their Google Drive. Uninstalling the Application or revoking OAuth access removes all local credentials.

4. Google API Services User Data Policy Compliance

Hub Backup's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. Prohibited Use

This Application does not use Google APIs for the creation, generation, or distribution of AI-generated Non-Consensual Intimate Imagery (NCII) or any other content prohibited by the Google APIs Terms of Service.

6. Security and User Control

OAuth tokens are stored securely on the operator's own server. The operator may revoke the Application's access to their Google account at any time by visiting https://myaccount.google.com/permissions and removing Hub Backup.

7. Contact
