Hub Backup

An automated, self-hosted backup utility for personal servers.

Purpose of the Application

Hub Backup is a private, command-line utility designed for a single operator. Its sole purpose is to automatically create compressed, encrypted backups of a server's databases, application files, and configuration. It then securely uploads these backups to a Google Drive folder that the operator has explicitly authorized, ensuring data can be restored in the event of hardware failure or data loss.

How It Works

  • Automated Backups: The tool runs on a schedule (via cron) on the operator's own server.
  • Data Collection: It creates a dump of a PostgreSQL database, a tarball of application source code, and a tarball of configuration files.
  • Google Drive Integration: It uploads the resulting backup files to a designated folder in the operator's Google Drive using the Google Drive API. The application is not a web service; it is a script that runs locally on the server.

Google API Compliance

This application uses the drive.file scope, which grants access only to files and folders it creates or that are specifically shared with it. It does not access any other data in the user's Google Drive. This application does not use Google APIs for the creation, generation, or distribution of AI-generated Non-Consensual Intimate Imagery (NCII) or any other prohibited content, in full compliance with the Google APIs Terms of Service.
