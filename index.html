Hub Backup

An automated, self-hosted backup utility.

What this application does

Hub Backup is a private, self-hosted utility that runs on a single server and automatically creates compressed backups of that server's databases, application files, and configuration. It uploads those backups to a Google Drive folder that the operator has explicitly authorized, so that the data can be restored in the event of hardware failure, accidental deletion, or other data loss.

How it works

  • Runs on a schedule (via cron) on the operator's own server.
  • Creates a PostgreSQL dump, a tarball of application files, and a tarball of configuration.
  • Uploads the resulting files to a Google Drive folder via the Google Drive API.
  • Uses OAuth 2.0 so the operator grants access to their own Google account once.

Who uses it

This application is used solely by its operator — a single individual managing their own server infrastructure. It is not a public service, does not have user accounts, and is not distributed to third parties.

Google Drive integration

Hub Backup requests only the drive.file scope, which limits access to files and folders that the operator has explicitly created or shared with the application. It does not read, modify, or delete any other files in the user's Google Drive.
